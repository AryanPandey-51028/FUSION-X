# 🎮 NEXTURN ARENA

### Your Squad. Your Game. Your Victory.

**NEXTURN ARENA** is an esports tournament registration and team recruitment platform developed for **Nexturn Society**.

The platform is designed to simplify player registration, team formation, and teammate recruitment for BGMI and Free Fire MAX tournaments.

---

## 🚀 About the Project

NEXTURN ARENA provides a centralized platform where gamers can create teams, discover existing teams, and request to join them.

Instead of managing registrations manually, the platform aims to make tournament participation easier and more organized.

## 🎯 Supported Games

- 🔫 Battlegrounds Mobile India (BGMI)
- 🔥 Garena Free Fire MAX

## 🏆 Team Formats

| Format | Maximum Players |
|---|---:|
| Duo | 2 |
| Squad | 4 |

## ✨ Key Features

- **Player Registration:** Register using real name, in-game name, and game UID.
- **Game Selection:** Choose BGMI or Free Fire MAX.
- **Team Creation:** Create your own Duo or Squad.
- **Find Teams:** Explore available teams.
- **Join Requests:** Apply to join teams and receive leader approval.
- **Team Management:** Manage team members and recruitment.
- **Admin Dashboard:** Manage tournament registrations.
- **Responsive Interface:** Designed for desktops, tablets, and mobile phones.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Firebase (planned/used for authentication and database integration)
